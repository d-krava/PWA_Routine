# My Routine — PWA

Личное приложение для заданий, привычек, тренировок, воды, заметок и статистики.

## Публикация на GitHub Pages

1. Создай бесплатный аккаунт на https://github.com.
2. Нажми **New repository**.
3. Название: `my-routine`.
4. Выбери **Public** → **Create repository**.
5. На странице репозитория нажми **uploading an existing file**.
6. Загрузи `index.html`, `manifest.json`, `service-worker.js` и папку `icons`.
7. Нажми **Commit changes**.
8. Открой **Settings → Pages**.
9. В **Build and deployment** выбери:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
10. Нажми **Save**.
11. Через 1–3 минуты открой:
`https://ТВОЙ_НИК.github.io/my-routine/`

## Установка на телефон

- Android / Chrome: меню ⋮ → **Установить приложение**.
- iPhone / Safari: «Поделиться» → **На экран «Домой»**.

## Данные

Пока данные хранятся локально в браузере устройства. Для синхронизации между телефоном и компьютером позже понадобится аккаунт и облачная база данных.
