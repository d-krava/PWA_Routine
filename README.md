# My Routine — полный комплект, версия 5

## Замена файлов
1. В текущем приложении: Ещё → Скачать копию. Сохраните JSON отдельно.
2. Распакуйте ZIP. Загрузите СОДЕРЖИМОЕ папки проекта в корень существующего репозитория. Не загружайте ZIP как сайт.
3. Замените index.html, tasks.html, habits.html, calendar.html, more.html, style.css, app.js, manifest.json, service-worker.js, папку icons. Имена должны быть точными — без « (1)».
4. GitHub → Commit changes. Дождитесь успешного развёртывания Pages в Actions.
5. Откройте существующий адрес с интернетом, закройте приложение полностью и откройте снова. При первом открытии ещё может работать старый кэш. Не удаляйте данные сайта.
6. Если раньше подключали mobile-fix.css/mobile-fix.js, их больше не нужно подключать: новые HTML уже самостоятельные. Старые файлы можно оставить — они не используются.

## Включено
- Мобильная форма задач с подписями; восемь кружков воды в одном ряду.
- Создание собственных типов активности с выбором цвета; редактирование имени и цвета; удаление неиспользуемого типа.
- Сначала выбирается день, затем активность. Запись сразу сохраняется. Одна активность на день. Отдельная кнопка снимает отметку.
- Сохранённые типы и цвета отображаются в полном и мини-календаре.
- Галочки привычек на Сегодня и Привычки; добавление и удаление на Привычки. История удалённых привычек остаётся.
- Светлая, тёмная и системная тема. SVG-иконки вместо эмодзи в меню.
- Заметка дня, экспорт и импорт JSON. Офлайн-кэш основных страниц.
- Автоматический переход ежедневных отметок на новую дату. Месяцы переключаются без пропуска.

## Данные
Хранилище по-прежнему myRoutine в localStorage. Старые задачи, привычки, история, заметки и календарь мигрируют автоматически при открытии на том же адресе и устройстве. Миграцию на ваших реальных данных отдельно не проверяли — сохраните копию.
У старой версии не было даты для doneToday и water. При первом переносе такие отметки относим к текущему дню; достоверно восстановить исходную дату нельзя. В новой версии вода и привычки привязаны к датам.
История привычек хранится под их именем, поэтому повторное добавление удалённой привычки с тем же именем восстановит её серию.
Синхронизации устройств нет. Импорт заменяет данные после подтверждения; старые копии поддерживаются.
Редактирование активности использует простые диалоги имени и HEX-цвета. При создании есть визуальный выбор цвета.
Это PWA с веб-оформлением в стиле iOS, не нативный Liquid Glass.

## Проверка после публикации
- На телефоне: вода 8 кружков в ряд, поля задачи читаемы, меню не закрывает конец страницы.
- Создайте «Плавание», задайте цвет, выберите дату и запишите активность.
- Отметьте привычку на Сегодня, проверьте её в Привычки; снимите отметку. Удалите тестовую привычку.
- Проверьте экспорт/импорт, смену темы, открытие страниц без сети после первого онлайн-запуска.
Тестирование в реальном Safari/iPhone в этой среде не выполнялось.
