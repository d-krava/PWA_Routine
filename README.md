# My Routine — полный комплект, версия 7

## Обновление одним разом
1. В установленной версии откройте Ещё → Скачать копию. Сохраните JSON отдельно.
2. Распакуйте архив и загрузите его СОДЕРЖИМОЕ в корень прежнего репозитория GitHub с заменой файлов. Не загружайте ZIP вместо сайта или папку-обёртку. Папка icons должна содержать иконки.
3. Имена без суффиксов: index.html, не index (1).html. Ничего вручную вставлять в HTML не нужно.
4. Commit changes. Дождитесь успешного развёртывания GitHub Pages в Actions.
5. Откройте тот же адрес онлайн, полностью закройте и снова запустите PWA. Кэш изменён на my-routine-v7-planning-history. При первом запуске ещё возможна старая версия. Не очищайте данные сайта.
6. Старые mobile-fix файлы не подключаются; их можно оставить. Новые страницы используют только app.js и style.css.

## Сегодня
Прогресс учитывает только задачи с планом на сегодня и привычки по расписанию. Дедлайн и история больше не смешиваются с планом дня. До трёх закреплённых невыполненных задач (кнопка «Важное сегодня» в задачах). Ближайшие встречи ищутся на 60 дней вперёд, выводится до трёх. Виджеты скрываются в Ещё → Настроить главную. Краткие показатели считают только выполненные активности, а не планы.

## Задачи
Дата плана и дедлайн отдельные. Фильтры Сегодня / Просрочено / Без плана / Все / Готово. Перенос на завтра. До трёх главных дел. Подзадачи: строки в форме; отмечаются в списке. Свои категории, переименование; использующуюся категорию удалить нельзя.
Повторение каждый день или каждую неделю: следующая задача создаётся ПОСЛЕ выполнения текущей. Не генерирует все будущие или пропущенные дни. Повтор наследует настройки текущей задачи и сбрасывает подзадачи. Снятие галочки не удаляет уже созданный следующий экземпляр. Редактирование или удаление одного экземпляра не меняет остальные созданные экземпляры.
Старые задачи автоматически не получают план на сегодня: смотрите Все / Без плана. Это сделано, чтобы не приписывать им неверную дату.

## Привычки
Стабильный ID сохраняет историю при переименовании. Режимы: ежедневно, выбранные дни, цель N дней за календарную неделю (понедельник–воскресенье). Норма за день и единица: например 20 минут. Галочка записывает полную норму; «Внести» позволяет вводить промежуточное количество. Недельная цель считается по дням с выполненной дневной нормой, не по сумме количеств за неделю.
Для ежедневного/выбранных дней серия пропускает дни вне расписания. Для недельного режима показывается прогресс недели, не ежедневная серия.
Архив не участвует в текущем плане. Возврат из архива сохраняет ID и историю. Удаление из списка оставляет историю по старому ID в данных; новая привычка с тем же именем НЕ подхватывает эту историю. Для временной паузы используйте архив.
Дата вверху страницы открывает историю и позволяет исправлять старые отметки. Это не отдельная тепловая карта: показаны отметки выбранного дня. Изменение нормы/расписания влияет и на интерпретацию истории — история конфигураций пока не хранится.
Перенесённая привычка «2 литра воды» сохраняет связь с трекером даже после переименования. Ручная отметка этой привычки на сегодня синхронизирует трекер с текущей целью воды. Новая произвольно названная привычка автоматически с водой не связывается.

## Календарь
Несколько активностей на дату. У каждой тип, дата, необязательное время и статус: запланировано / выполнено / отменено. Активности создаются через кнопку Добавить в блоке Активности. Типы и цвета настраиваются отдельно. Календарь показывает до четырёх цветных точек, детали — в списке дня. Отменённые активности не показывают точку, но остаются в списке.
План не считается выполнением. Старые записи прошлых дат переносятся как выполненные, будущих — как планы (исходная версия не различала статусы).
Вид Ближайшие 7 дней: встречи и активности по времени на каждой дате, включая отменённые со статусом.
Встречи: дата, начало/окончание, место, заметка; без времени — весь день. Повтор ежедневно или еженедельно, необязательная дата окончания. Редактирование/удаление меняет ВСЮ серию; исключений для одного повтора нет.
При сохранении встречи предупреждение о пересечении проверяет её первую дату; все будущие повторы заранее не анализируются. При сохранении активности проверяется её дата. События без времени не считаются конфликтами; без окончания — минутный интервал для проверки. Это подсказка, не запрет на пересечения.
События через полночь пока не поддерживаются: создайте две записи. Время местное, без преобразования часовых поясов. Поиска по встречам в этой версии нет.

## Вода
Личная цель, размер порции, кнопки добавления порции и 500 мл, отмена до 30 предыдущих действий за день. Восемь кружков всегда в один ряд; каждый означает 1/8 выбранной цели. Значение может превышать цель при добавлении порциями. Цель — личная настройка учёта, не медицинская рекомендация.
Настройка скрытия доступна в трекере и Ещё. Суточные значения привязаны к датам. Просмотр отдельного архива воды не добавлен; данные находятся в JSON-копии.

## Заметки и данные
В Ещё можно выбрать дату и читать/редактировать прошлые заметки. Светлая/тёмная/системная тема. Экспорт/импорт JSON.
Данные локальные, без аккаунтов, облачной синхронизации и фоновых уведомлений. Интеграции с Apple Calendar нет. Медицинские заметки не шифруются отдельно — избегайте лишних чувствительных подробностей.

## Миграция
Ключ localStorage остаётся myRoutine. Сохраняются прежние поля, добавляются новые структуры habitLogs, activityLogs, activityTypes, water, categories, prefs. История привычек по именам преобразуется в историю по ID. Старая вода переводится из кружков по 250 мл в миллилитры. Встречи, заметки и типы активности переносятся. Старые структуры остаются в копии для совместимости, но новой логикой не используются.
При переносе версий до 5 отметки без даты относятся к дню переноса — исходную дату восстановить невозможно. Импорт копий старых версий поддерживается; он заменяет данные после подтверждения. Не используйте старую версию приложения для правок после перехода на v7.

## Проверки
Выполнены проверка синтаксиса app.js/service-worker.js в Node, проверка ссылок на локальные ресурсы, программные тесты миграции v6→v7 и повторной миграции, повторений встреч и задач, пересечений времени, сохранения истории при переименовании, построения всех экранов и форм с тестовой DOM-заглушкой.
Это НЕ тест в браузере. Реальное отображение в Safari/iPhone, клавиатура, скролл модальных форм, офлайн и установка PWA требуют проверки на устройстве.

Проверка после публикации: перенесите копию на безопасном тестовом устройстве; проверьте старые записи. Создайте задачу с планом/дедлайном/подзадачами; привычку 20 минут по будням; две активности на одной дате; повторяющуюся встречу; прочитайте прошлую заметку; измените цель воды и отмените добавление. Проверьте экспорт, темы, поворот экрана и офлайн после онлайн-загрузки.
