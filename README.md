# My Routine — версия 6

ГОТОВЫЙ КОМПЛЕКТ ДЛЯ ЗАМЕНЫ

1. В старой версии приложения откройте «Ещё» → «Скачать копию» и сохраните JSON.
2. Распакуйте архив. Загрузите всё СОДЕРЖИМОЕ архива в корень прежнего репозитория GitHub, заменив одноимённые файлы. Не загружайте ZIP вместо сайта. Папка icons должна остаться папкой.
3. Никаких вставок кода не требуется. Имена точные: index.html, не index (1).html.
4. Commit changes → дождитесь успешного развёртывания Pages в Actions.
5. Откройте приложение онлайн, полностью закройте и откройте снова. При первом запуске ещё возможен старый кэш. Кэш обновлён до my-routine-v6-meetings-ios. Не очищайте данные сайта.
6. Старые mobile-fix.css и mobile-fix.js не используются новыми страницами; можно оставить.

ВСТРЕЧИ
«+» на Сегодня или Календарь → название, дата, время начала, время окончания, место, заметка. Без времени — весь день. Окончание, если указано, должно быть позже начала в тот же день. Несколько встреч в один день поддерживаются. Время — местное, без преобразования часовых поясов. Встречи могут пересекаться.
Точка под датой означает наличие встречи. Выберите дату: справа/ниже появится список встреч. «···» открывает редактирование и удаление.
На Сегодня — ближайшие предстоящие встречи (до трёх). События на весь день остаются на Сегодня до конца даты. Для события без окончания после времени начала оно больше не считается предстоящим, но остаётся в календаре.
Фоновых уведомлений, приглашений, интеграции с Apple Calendar и синхронизации нет. Не полагайтесь на приложение как на единственное напоминание о медицинском визите.

ОФОРМЛЕНИЕ
Сгруппированные списки, более компактная главная, монохромные иконки, светлая/тёмная/системная тема. Задачи и привычки добавляются через «+» и нижнюю модальную форму. Формы дат ограничены шириной контейнера. Восемь кружков воды в один ряд.
На компьютере формы открываются по центру, меню сбоку. На телефоне формы — нижняя шторка, меню плавающее.
Это веб-интерфейс в стиле iOS, не нативные компоненты или настоящий Liquid Glass.

СОХРАНЕНО
Задачи с категориями, приоритетами, дедлайнами и отметками; редактирование/удаление через «···». Привычки и серии, галочки на Сегодня и Привычки, удаление с сохранением истории. Вода по датам. Пользовательские активности: название и цвет, создание и редактирование; одна активность на день. Список типов: Календарь → Активность → Настроить. Тип с историей нельзя удалить, пока используются его записи. Заметка дня. Экспорт/импорт. Офлайн после первого успешного онлайн-запуска.

ДАННЫЕ
Используется прежний ключ localStorage: myRoutine. Автоматический перенос задач, привычек, календаря, заметок, воды и пользовательских активностей из версии 5. Поля предыдущей версии сохраняются, встречи добавляются отдельным массивом appointments. Старые копии поддерживаются.
Для версий до 5 ежедневные отметки без даты относятся к текущему дню при переносе: исходную дату достоверно восстановить нельзя.
Импорт заменяет данные после подтверждения. Синхронизации между устройствами нет. Медицинские заметки лучше хранить без лишних чувствительных подробностей; приложение не шифрует их отдельно.

ПРОВЕРКА
Создайте встречу «Врач», выберите дату/время/место; проверьте точку в календаре, список дня, редактирование/удаление. Создайте две встречи на одной дате. Проверьте задачу, привычку, цвета активности и воду. Проверьте обе темы, открытие офлайн после онлайн-загрузки. На реальном iPhone/Safari тестирование в среде генерации не выполнялось.
